# Grant Pack

The Grant Pack (`1._GP_Template`) is edited on the team OneDrive, in "Grant Pack Work".
Final submission: 23 November 2026 (DE submits).

Key decisions recorded in the Grant Pack:
- Sensor: thermal camera (FLIR Lepton 3.5 on a PureThermal 3 board).
- Method: passive thermography in the field; a lamp simulates solar heating in the lab.
- Two drones image the same area from different angles to reject reflections,
  benchmarked against a single drone.
- GPS-denied navigation in the drone lab.
